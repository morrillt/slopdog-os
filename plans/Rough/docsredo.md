### Document Types

We will create different menu handlers for various document types:

1. **User How-To's**: Documents explaining how to use the system.
   
2. **Research Docs**: These will explore multiple options for tackling a problem, including best practices and implementation strategies.
   
3. **Dev Notes**: Notes for future developers, detailing workarounds and potential hiccups.

### Templates and Publishing

For each document type, we will develop simple templates over time, utilizing the facets and tags drafted across various documents. 

When we publish, we will:
- Add all relevant tags and facets.
- Create basic facets during document creation.
- Include a human-readable summary for UI, akin to tweet-sized text.
- Add a summary optimized for vector storage, around 300-400 words, focusing on dense information rather than readability.
