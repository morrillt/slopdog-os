# Broz Core System

This rule is the global context provider for the Broz workflow system.

## Context Loading
Always be aware of the `plans/context.yaml` file. It defines the current mode and active tasks.

## Critical Guardrails
1.  **BUILD Mode**: You may ONLY edit code files if `current_mode` is 'build' AND a `current_ticket` is active.
    - If in 'plan' mode, you can write to `plans/` but not `src/`.
    - If in 'research' mode, you can write to `docs/research/` but not `src/`.
2.  **Strict Gating**: Do not bypass the ticket system for feature work. One-off tasks go to TASK mode.

## Persona Switching

# Workflow: Build > Code Review Ticket

Slimmed version of BMAD's `code-review`.

## Goal
Verify **every Acceptance Criterion** and every **checked** task has real evidence.

## Steps

1. **Load Ticket**:
   - Read `plans/context.yaml` for `execution.current_ticket`.
   - Read the full ticket file.

2. **Collect Claimed Changes**:
   - From `### File List`, gather the set of files claimed modified.
   - If empty or suspicious, broaden search by looking at files touched in this session.

3. **Validate Acceptance Criteria (ACs)**:
   For each AC:
   - Mark as `IMPLEMENTED | PARTIAL | MISSING`.
   - Record evidence: `path:line-range` where it’s satisfied.
   - Record test evidence: which test(s) prove it.

4. **Validate Completed Tasks**:
   For each task marked `[x]`:
   - Mark as `VERIFIED | QUESTIONABLE | NOT DONE`.
   - If `[x]` but `NOT DONE`, treat as **BLOCKER**.

5. **Outcome**:
   - **APPROVE**: all ACs implemented, all checked tasks verified, tests pass.
   - **CHANGES REQUESTED**: partial/missing ACs or questionable tasks.
   - **BLOCKED**: any false completion or critical gap.

6. **Write Review Notes Into Ticket**:
   Append under `## Dev Agent Record` (create if missing):
   - `### Code Review`
     - Date
     - Outcome
     - Findings (bullet list; blockers first)
     - Action Items (checkbox list)

7. **State Transition**:
   - If APPROVE: ticket `Status:` can move `Review → Done`.
   - If CHANGES REQUESTED: move `Review → In Progress` and add action items to Tasks.
