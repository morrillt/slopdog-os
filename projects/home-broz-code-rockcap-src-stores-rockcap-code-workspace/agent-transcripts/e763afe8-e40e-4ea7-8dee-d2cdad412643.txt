## Key Sensitivities

### 1. Max Round Trips (CRITICAL)

**Impact:** Highest sensitivity parameter

- **MaxRT = 3:** Average profit **137.77 points** (112% above overall average)
- **MaxRT = 2:** Average profit **64.92 points** (36% below overall average)

### 2. Trigger Margin (HIGH)

**Impact:** Strong differentiation between values

- **Trigger = 7:** Average profit **131.28 points** (30% above overall average)
- **Trigger = 5:** Average profit **71.41 points** (30% below overall average)

- **TP = 30:** Average profit **60.34 points** (40% below average)

**Finding:** Higher TP levels (150-200) consistently outperform, indicating the strategy captures extended moves effectively.

- **SL = 8:** Average profit **92.52 points** (9% below average)
