# BUG: 20251216-tp-relative-to-trigger TP Calculation Incorrectly Relative to Open Instead of Trigger
Status: In Progress

## Bug Summary
The Take Profit (TP) price level is currently being calculated relative to the candle Open price, but it should be calculated relative to the Trigger (TRG) price. This results in incorrect TP levels when a Trigger offset is used.

## Stakeholder Notes (raw)
> The TP should be the price above the trigger. So in this, I'm going to send you this URL where you can see it's at 50 as a TP and then a trigger at 8. So you would expect there to be a difference of 12. But I'm actually going to switch it so that it's a little bit more even numbers for me so I can look at it a little bit easier. So it's basically the open is at 25,526 and then the TP is 25,576. So it's using the start price to establish the TP, but it should be above the trigger. The TP should be set relative to the trigger and not the open.

## Expected Behavior
When a strategy has a Trigger (TRG) offset and a Take Profit (TP) target:
- The Trigger Price is calculated relative to Open (e.g., Open + TRG).
- The TP Price should be calculated relative to the **Trigger Price** (e.g., Trigger Price + TP), NOT relative to the Open.

Example:
- Open: 100
- TRG: +10 (Trigger Price = 110)
- TP: +50
- Expected TP Price: 110 + 50 = 160

## Observed Behavior
Currently:
- The TP Price is calculated relative to Open (e.g., Open + TP).

Example (Observed):
- Open: 100
- TRG: +10
- TP: +50
- Observed TP Price: 100 + 50 = 150 (Incorrect)

## Repro Steps
1. Navigate to: `http://localhost:3000/backtest/2025-12-02?strategy=strategy12.10.1&pt=50&sl=10&trg=10&candleType=1s&cutoffTime=09%3A45`
2. Observe the TP line level.
3. Compare with Open Price and Trigger Price.
4. See that TP is exactly Open + 50, ignoring the Trigger offset.

## Scope / Impact
Affects all backtest strategies that use both a Trigger offset and a Take Profit target. Critical for strategy correctness.

# BUG: 20251216-tp-relative-to-trigger TP Calculation Incorrectly Relative to Open Instead of Trigger
Status: Review

## Bug Summary
The Take Profit (TP) price level is currently being calculated relative to the candle Open price, but it should be calculated relative to the Trigger (TRG) price. This results in incorrect TP levels when a Trigger offset is used.

## Stakeholder Notes (raw)
> The TP should be the price above the trigger. So in this, I'm going to send you this URL where you can see it's at 50 as a TP and then a trigger at 8. So you would expect there to be a difference of 12. But I'm actually going to switch it so that it's a little bit more even numbers for me so I can look at it a little bit easier. So it's basically the open is at 25,526 and then the TP is 25,576. So it's using the start price to establish the TP, but it should be above the trigger. The TP should be set relative to the trigger and not the open.

## Expected Behavior
When a strategy has a Trigger (TRG) offset and a Take Profit (TP) target:
- The Trigger Price is calculated relative to Open (e.g., Open + TRG).
- The TP Price should be calculated relative to the **Trigger Price** (e.g., Trigger Price + TP), NOT relative to the Open.

Example:
- Open: 100
- TRG: +10 (Trigger Price = 110)
- TP: +50
- Expected TP Price: 110 + 50 = 160

## Observed Behavior
Currently:
- The TP Price is calculated relative to Open (e.g., Open + TP).

Example (Observed):
- Open: 100
- TRG: +10
- TP: +50
- Observed TP Price: 100 + 50 = 150 (Incorrect)

## Repro Steps
1. Navigate to: `http://localhost:3000/backtest/2025-12-02?strategy=strategy12.10.1&pt=50&sl=10&trg=10&candleType=1s&cutoffTime=09%3A45`
2. Observe the TP line level.
3. Compare with Open Price and Trigger Price.
4. See that TP is exactly Open + 50, ignoring the Trigger offset.

## Scope / Impact
Affects all backtest strategies that use both a Trigger offset and a Take Profit target. Critical for strategy correctness.
