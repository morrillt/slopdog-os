# BUG: BUG-20251216-cutoff-time-force-close Cutoff Time Force Close Not Respected
Status: Pending  <!-- Pending | Ready | In Progress | Review | Done -->

## Bug Summary
At the end of the interval (cutoff time), any open positions should be force closed. This rule should apply to both the first interval (9:35) and the cutoff time (e.g., 9:40). Currently, the cutoff time is not respected - positions remain open past the cutoff time instead of being force closed. Additionally, the default cutoff time should be changed from 9:45 to 9:40 as the standard.

## Stakeholder Notes (raw)

And so this should apply both to the first interval as well as the cutoff time. So I will send you a link to a cutoff time at 9:40, which was not respected. ## Expected Behavior
1. **Force Close at Cutoff Time**: When the cutoff time is reached (e.g., 9:40), any open positions should be automatically force closed at the close price of the candle immediately before the cutoff time candle.
2. **Force Close at First Interval (9:35)**: This should already be working (similar to existing "Forced 9:35 Close" logic).
3. **Default Cutoff Time**: The default cutoff time should be 9:40 instead of 9:45.

## Observed Behavior
1. **Cutoff Time Not Respected**: When cutoff time is set to 9:40, positions remain open past 9:40 instead of being force closed. The last trade in the example shows an "Open Long" at 09:35:10 ET, but no corresponding "Close Long" entry at or after 9:40.
2. **Default Cutoff Time**: Currently defaults to 9:45 instead of the desired 9:40.
