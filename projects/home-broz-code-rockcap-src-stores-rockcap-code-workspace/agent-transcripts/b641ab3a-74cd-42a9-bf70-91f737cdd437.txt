**Wayland** is a display server protocol for Linux (and other Unix-like systems). It’s a modern replacement for X11 (X Window System).

## Key points

**What it does:**
- Manages how applications draw to the screen and handle input (keyboard, mouse, touch)
- Sits between your desktop environment/window manager and the graphics hardware

**Wayland vs X11:**
- **X11** — older, widely used, but has security and performance limitations
- **Wayland** — newer, designed to be simpler, more secure, and performant

**Why it matters:**
- Better security (apps can’t spy on each other)
- Smoother animations and better performance
- Simpler architecture
- Some apps/tools work better on Wayland (like Wayclip)

**How to check if you're using Wayland:**
```bash
echo $XDG_SESSION_TYPE
```
If it says `wayland`, you're on Wayland. If it says `x11` or `xorg`, you're on X11.

**Common Wayland desktops:**
- GNOME (default on many distros)
- KDE Plasma (can use Wayland)
- Sway, Hyprland (Wayland-native)

Most modern Linux distributions default to Wayland on GNOME, but you can switch back to X11 if needed.

## Main differences

**Security:**
- **X11**: Apps can see each other's windows and capture input (keyloggers/screen capture possible)
- **Wayland**: Apps are isolated; can't spy on each other

**Performance:**
- **X11**: Older architecture, can have tearing/stuttering
- **Wayland**: Smoother animations, better GPU handling, compositor handles vsync

**Architecture:**
- **X11**: Client-server model (apps talk to X server)
- **Wayland**: Simpler, direct communication with compositor

**Compatibility:**
- **X11**: Older apps often assume X11; some tools rely on X11 features
- **Wayland**: Newer apps work well; older ones may need XWayland (compatibility layer)

**For screen recording:**
- **X11**: More tools available (e.g., OBS, SimpleScreenRecorder)
- **Wayland**: Needs PipeWire for screen capture; some tools don't work yet
