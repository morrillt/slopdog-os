        O(112) -> L(110).
        Stop 111. Entry 100.
        O(112)->L(110) crosses Stop(111).
        L(110)->H(120).
        Entry(100) never reached?
        Wait, if L is 110, and Entry is 100, we never fill anyway.
        
        So for Short (Entry < Stop) on Green Candle (Low then High),
        it is HARD to hit Stop (High) before Entry (Low) unless:
        Stop is in O->L segment?
        O(100) -> L(90).
        Stop must be between 100 and 90?
        If Stop is < O?
        Entry must be < Stop.
        Entry 80. Stop 95.
        O(100) -> L(90).
        Crosses 95(Stop), then 80(Entry)? No, 90 is lowest.
        Crosses 95. 80 not reached.
        So NO_FILL (Entry not reached).
        
        What if Entry reached later?
        O->L crosses Stop.
        L->H crosses Entry? No, L is lowest. H is highest.
        If Entry is 105 (on L->H). Stop is 95 (on O->L).
        Stop(95) < Entry(105). INVALID setup for Short (Stop must be > Entry).
        
        Conclusion: On Green Candle (O->L->H->C), it is almost impossible to hit Short Stop (>Entry) before Short Entry (usually < Price),
        BECAUSE Stop is High and Entry is Low.
        And Green Path goes Low FIRST (O->L), then High (L->H).
        
        Exception: If Entry is HIGH (limit sell above market).
        Entry 105. Stop 110.
        O(100) -> L(90) -> H(115).
        L->H crosses 105 then 110.

        O(112). Stop 114. Entry 115.
        O->L(110). No.
        L->H(120). Crosses 114 then 115.
        Stop hit before Entry?
        110 -> 114(Stop) -> 115(Entry).
        Yes.
      

Why This Outcome:

        Short Limit Entry at 115. Stop at 114?
        No, Short Stop must be > Entry. Stop 118.
        110 -> 115(Entry) -> 118(Stop).
        Fill then Stop.
        
        So "Blocked by Stop" for Short Green is rare/impossible if Stop > Entry and Entry > Low.

        Target < Entry.
