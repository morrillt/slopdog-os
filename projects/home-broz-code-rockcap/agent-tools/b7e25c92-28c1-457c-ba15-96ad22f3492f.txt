 # Workflow: Plan > Validate Ticket
 
-Ensures a ticket is ready for development by checking its structure.
+Validates (and, when needed, **extends**) a ticket so it is coherent, testable, and ready to execute via `build/continue`.
+
+This workflow is intentionally **stricter and more explicit** than a simple “format check”:
+- It checks coherence across the ticket (story → ACs → tests → tasks).
+- It pushes **one layer deeper** on test cases (stakeholder-clear expectations + a tiny “how”).
+- It records unanswered ambiguity as **front-matter questions** (`questions.items`).
+- It can optionally mark the ticket **Ready** as the final step (for handoff).
