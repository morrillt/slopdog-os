# The Slopdog crew style

The house look for a crew avatar. **Use this template for anything that has to sit beside
the Captain, Princess Lu or Gemmy** — do not improvise a style and do not copy a
`prompt_*.txt` out of `banananano` without checking it against the images below, because
several of those files are rejected attempts kept under the character's name.

## Why this file exists

Gemmy was drawn wrong once (2026-09-06) because his prompt was based on
`banananano/prompt_lu_avatar.txt` — a file named for Lu that produced a **flat pop-art
fox on a gold sunburst**, nothing like her. The prompt that actually made Princess Lu was
written into a session scratchpad, which was wiped, so the winning recipe existed nowhere
on disk while a losing one sat in the repo wearing her name.

**The rule that follows: the prompt that produced a keeper is saved beside the keeper.**

## The five things that make it the crew

Miss any one and it reads as a different universe:

1. **Swirling cosmic nebula background** — deep purple, hot magenta, electric blue and
   teal, scattered small white stars, and a **bright spiral core behind the head**.
2. **Round black circular sunglasses with a swirling purple-and-blue galaxy reflected in
   each lens.** This is the single strongest signature. Every crew member wears them.
3. **A rounded-rectangle name plate across the top** — dark navy fill, glowing neon cyan
   outline, the name in bold condensed uppercase white letters.
4. **Thick clean black outlines, cel-shaded flat colour, soft glowing rim light.**
5. **Head-and-shoulders portrait**, centred, filling most of the frame, cropped at the
   chest. Square 1:1.

## The template

Fill the three bracketed parts. Everything else is fixed.

```
Square 1:1 profile avatar illustration of a character called [NAME], drawn in a bold pop-art comic style.

Art style: thick clean black outlines, cel-shaded flat colour with soft glowing rim light, high-contrast digital comic illustration. The background is a swirling cosmic nebula in deep purple, hot magenta, electric blue and teal, with scattered small white stars and a bright spiral core behind the character's head. Head-and-shoulders portrait, character centred and filling most of the frame, cropped at the chest.

Character: [the animal, its build and colouring, in two or three clauses]. [Its wardrobe — one or two pieces, described plainly.] It wears round black circular sunglasses with a swirling purple-and-blue galaxy reflected in each lens. Its expression is [two or three adjectives that are the character's personality, not a pose].

Banner: across the top of the image, a rounded-rectangle name plate with a dark navy fill and a glowing neon cyan outline, containing the text "[NAME]" in bold condensed uppercase white letters.

Poster-quality, clean, high-impact, vibrant.
```

## The Catpuccin house palette — in the words the configs use

Recovered 2026-09-06 from `banananano`'s own git history (commit `a6484a1`), where a
layered config engine had been dropped by the ThinkPad→Mac migration. `configs/*.json`
state the brand in XML rule blocks, and this is the palette wording Todd used repeatedly:

> **Palette** — strictly follow the 'Catpuccin' brand palette: **deep mocha and onyx** for
> the void of space, **soft lavender and mauve** for the nebula's highlights, and
> **vibrant rose/cyan** for the energetic glowing gas clouds and distant stars.
>
> **Vibe** — 80s synthwave cinematic glow. Stars and nebula centres have a soft, ethereal
> light-bleed; the colours pop with neon energy against the dark void.
>
> **Style DNA** — bold black ink outlines, flat 2D cell-shading, simplified features.

The colour anchor image is `banananano/refs/abstract-swirlscatpuccin.jpg`, and the Captain
reference is `refs/slopdog.png`. Both are named directly by the configs.

The Captain's own signature, stated in `slopdog-crew-new.json`: *"round cosmic sunglasses;
pink polka-dot bandana; tongue out licking nose (signature trademark)"*.

## The layered config engine

`generate-pro.js --json configs/<name>.json` is the richer path, and it is how the brand
art was made. A config is a **mission** — subject plus `<BrandRules>`, `<TitleRules>` and
`<AppRules>` as XML blocks — and a list of **transformations**, each one a prompt **plus a
reference image**, applied in order:

1. **Artistic Foundation** — extract the line style from a reference.
2. **Character Master** — copy a character faithfully from its reference.
3. **Brand Color Identity** — anchor the palette to `abstract-swirlscatpuccin.jpg`.
4. **Cinematic Vibe** — the synthwave glow.

Start from `configs/catpuccin-space.json` for a background, `configs/slopdog-crew-new.json`
for a crew scene, or `configs/template-crew-bridge.json` for a fresh one.

**It runs on Gemini, which is the API returning `limit: 0` on this key** — so the engine is
recovered and readable but not runnable until billing is on. The single-prompt
`generate-openai.mjs` path is what works today, and it takes no reference images, which is
why the palette has to be spelled out in words there.

## How to run it

Per the skill: `generate-openai.mjs`, gpt-image-1, **`--size 1024x1024`**. The OpenAI path
takes no reference image, which is exactly why the style has to be this explicit in words.

If Google billing is ever switched on, `generate.js -pro --image <a crew avatar>` matches
the style from the picture instead of the description, and will hold the look more tightly
than any wording. That is the better path the day it exists.

## Don't

- Don't drop the galaxy sunglasses or the nameplate to "modernise" it.
- Don't use a sunburst background. That is the rejected look.
- Don't ask for text beyond the nameplate; the model cannot spell.
